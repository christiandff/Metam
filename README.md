MARBLE - Strength Training App
Forged in Marble. Built in Iron.

Overview
MARBLE er en mørk, estetisk og seriøs treningsapp inspirert av gresk skulptur og disiplin.
Appen kombinerer progressive overload, rituelle treningsopplevelser og et cinematic dark‑mode UI for å gi brukeren følelsen av å forme sin egen statue, sett for sett.

Features
Progressive Overload Engine  
Automatisk forslag til neste ukes vekt og reps basert på prestasjon, øvelsestype og rep‑range.

Warm‑Up Sets  
To automatiske warm‑ups per øvelse, generert basert på dagens målvekt. Warm‑ups er separate fra arbeidssettene og teller ikke i volum.

Workout Logging  
Minimalistisk dark‑mode UI med raske input‑felt og tydelige progresjonsforslag.

Session Summary  
Viser totalvolum, PR‑deteksjon, beste og svakeste øvelse, samt forslag til neste økt.

Cardio Mode  
Valgfri cardio etter økt (stairmaster, jogging, sykling, gåing) med innebygd timer og intensitetsvalg.

Aesthetic Identity  
Hvit lineart av klassiske statuer, marmor‑inspirerte elementer og en helhetlig gresk‑inspirert visuell stil.
